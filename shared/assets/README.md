# Shared assets

Small, engine-neutral source files used by every engine. Each file has an id, size and SHA-256 in `../../asset-manifests/assets.json`; engines look assets up by id and never keep their own copy as the source of truth. Large packages go to `../../external-assets/` instead (see `docs/USB_ASSETS.md`).

- `audio/fire.wav`, `audio/impact.wav` — 22 050 Hz mono, generated by `tools/generate_shared_audio.py`.
